Features

Everything you need to reclaim space.
Nothing you don't.

A command-line tool with a browser UI. It runs locally, keeps nothing, and gets out of the way.

⚡

Seriously fast scanning

Uses macOS getattrlistbulk to read whole folders in one call, across parallel workers. Sizes match du exactly.

▦

Interactive treemap

Nested, color-coded by file type. Hover for details, double-click to drill in, right-click to reveal or trash.

✦

Safe clean-up

Finds node_modules, build caches, Xcode data and package caches, and explains why each one is safe to remove.

⇩

Shareable reports

tpdv report writes one self-contained HTML file. It opens anywhere, works offline, and has the full treemap.

🔒

Private by design

The UI is served on 127.0.0.1 with a one-time token. Nothing is uploaded, and there's no telemetry.

›_

Terminal friendly

tpdv top and tpdv suggest print the biggest items and clean-up candidates without opening a browser.

Clean up

Know what's safe to delete before you delete it.

Every suggestion comes with a safety level, a one-line reason, and the tool's own cleanup command where there is one.

  • SafeCaches and build output that come back automatically: .next, DerivedData, app caches, logs.
  • RebuildableRestored by a command; costs time, not data: node_modules, .venv, target, .terraform, Pods.
  • Review firstMight hold things you want: Docker data, archives, simulators, old runtimes, installers.
  • Project folders need a marker file, like package.json next to node_modules
  • Everything goes to the Trash, so Put Back works
  • System folders and tool-managed data are refused

Get started

Up and running in one command.

Needs Go 1.22 or newer. Grant your terminal Full Disk Access to include protected folders.

# install
$ go install github.com/ratan99/tp-disk-visualizer/cmd/tpdv@latest

# or build from source
$ git clone https://github.com/ratan99/tp-disk-visualizer
$ cd tp-disk-visualizer && make install
$ tpdv                 # your home folder, in the browser
$ tpdv /               # the whole disk
$ tpdv suggest         # what you can clean
$ tpdv report ~ -open  # shareable HTML report
$ tpdv top ~/Downloads # terminal summary
